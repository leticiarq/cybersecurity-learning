# Minha base de estudos em segurança web

Este repositório é a base que estou construindo para estudar e revisar segurança em aplicações web. Organizei cada assunto partindo de uma situação concreta, passando pelo funcionamento passo a passo e chegando aos termos técnicos.

## Por onde começar

1. Começar pelo módulo de [segurança de autenticação](web-security/authentication/README.md).
2. Revisar os fundamentos: identidade, login, sessão, tokens, MFA e senhas.
3. Estudar JWT e comparar os algoritmos HS256 e RS256.
4. Executar a atividade prática para observar a criação e a validação dos tokens.
5. Revisar as vulnerabilidades e tentar explicar cada falha com minhas próprias palavras.

> Meus testes devem ficar restritos a sistemas próprios ou ambientes em que eu tenha autorização explícita.
